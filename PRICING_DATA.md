## Audit engine notes

- When a user is on a team plan, per-user cost is calculated: Team plan total cost / team size
- Audit engine recommends downgrades when team size < plan minimum (e.g., ChatGPT Team for 2 people is inefficient)
- Overlap detection flags tools in same category (e.g., Claude Pro + ChatGPT Plus both for general reasoning)
- Savings are calculated as: (current annual spend) - (recommended annual spend), always shown as positive
- For API-direct users, spend is calculated from token usage estimate; recommendations suggest moving to prepaid credits if volume high
